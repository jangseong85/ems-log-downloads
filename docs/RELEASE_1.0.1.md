# EMS Log 1.0.1

배포일: 2026-10-08 · Android versionCode: 2 · 패키지: com.emslog.mobile

- SALS 타이머: CPR 누적 경과, 2분 사이클, 리듬 분석 및 제세동 횟수, 에피·아미오다론 투여, ROSC·재심정지 기록.
- 24시간 형식 시각 수정, 항목별 리셋 확인, 사건 목록 및 마지막 기록 취소.
- 백그라운드 복귀 시 기록 시각 기준 경과 계산 및 중단 후 임시 복구.
- 앱 전체 타이포·입력·버튼·카드 규격 정리.

기존 홈페이지 1.0.0과 동일한 배포 키를 유지하며 versionCode를 1에서 2로 증가시켰다. 예전 개발용 서명 설치본과는 다르다.

ARM64 APK, 기존 도구 `gjfire-tools/tools/sign-android-apk.mjs`로 서명·패키지·인증서·정렬 검증. 타입/린트 및 타이머 단위 테스트 9개 통과. 실기기 검증은 별도 필요하다. 치료 권고나 투약 알림을 제공하지 않는다.

에뮬레이터 실행 검증은 ADB 인증 대기로 완료하지 못했다. npm 점검에서 기존 의존성 취약점 44건(중간 13/높음 30/치명적 1)이 보고됐으며, 이번 배포에 강제 의존성 업데이트는 포함하지 않았다. 별도 보안 점검이 필요하다.
