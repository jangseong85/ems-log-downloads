# SALS 스피드 타임라인 PRD

- 버전: v2.1 — CPR pause 및 리듬 확인 최적화
- 작성일: 2026-09-28
- 대상: EMSLog 모바일 앱
- 범위: 성인 심정지 개인 기록
- 주 사용자: 현장 팀리더

## 1. 제품 정의

SALS 타임라인은 팀리더가 성인 심정지 현장에서 이미 발생한 사건과 시행된 처치의 시각을 빠르게 남기는 개인 기록 도구다.
환
이 앱은 다음 처치를 추천하거나 약물 용량·경로, 제세동 에너지를 지시하지 않는다. 병원 인계나 기관 공식 기록을 대신하지 않는다.

## 2. 목표

- 자주 쓰는 사건은 한 번 탭하여 기록한다.
- 화면을 열면 전체 경과, 현재 CPR cycle, 최근 기록을 즉시 확인한다.
- 잘못 누른 기록은 바로 취소한다.
- 늦게 입력한 사건은 실제 발생시각으로 쉽게 수정한다.
- 최초 심정지, ROSC, 재심정지를 시간 흐름으로 명확하게 구분한다.
- 앱이 종료되어도 진행 중 기록과 타이머를 복구한다.

## 3. 제외 범위

- 소아·신생아 심정지
- 리듬 자동 판독
- 처치·약물·제세동 권고
- 기관별 프로토콜 관리
- 병원 인계 양식
- 클라우드 동기화
- 음성 입력과 통계 분석

## 4. 현재 화면의 핵심 문제

| 문제 | 영향 | 변경 |
|---|---|---|
| 모든 기록이 하나의 배열에 저장됨 | 이전 환자 기록과 섞일 수 있음 | 환자별 SALS 세션 분리 |
| 38:62 비율의 2열 화면 | 타임라인과 버튼이 모두 좁음 | 전체 폭 단일 열로 변경 |
| 모든 버튼이 계속 노출됨 | 탐색과 스크롤이 느림 | 핵심 버튼 고정, 나머지는 더보기 |
| CPR 버튼을 눌러야만 2분 타이머가 다시 시작됨 | 실제 cycle과 화면이 어긋날 수 있음 | CPR cycle을 별도 기록 단위로 관리 |
| 리듬과 리듬 확인 행위가 구분되지 않음 | 각 cycle의 리듬 변화가 불명확함 | `리듬 확인 → 결과 선택`으로 기록 |
| ±1분만 수정 가능 | 실제 시각 보정이 어려움 | 시·분·초 편집과 빠른 보정 제공 |
| 즉시 되돌리기가 없음 | 오입력 수정이 느림 | 기록 후 5초 실행 취소 제공 |
| 초기화가 전체 삭제 방식 | 기록 손실 위험 | 세션 종료 후 개별 삭제 방식으로 변경 |

## 5. 한 화면 구조

탭 메뉴를 만들지 않는다. 모든 사건을 하나의 세로 타임라인에 표시하고, `초기 진행`, `2분 CPR cycle`, `병행 처치`, `ROSC/재심정지`를 카드와 구분선으로만 나눈다.

```text
┌─────────────────────────────────┐
│ SALS 기록 중          14:32:18  │
│ 총 CPR 08:24  │  Cycle 4  01:12 │
│ Shock 2회     │  Epi 2회  02:18 │
├─────────────────────────────────┤
│ 초기 진행  4/4 완료             │
│ 접촉 14:22 · CPR 14:23 · AED 14:24│
│ Initial rhythm VF 14:24          │
├─────────────────────────────────┤
│ ● Cycle 4              01:12 남음│
│ 14:31:34  Epinephrine 2회        │
│ 14:31:12  제세동 2회             │
│ 14:31:08  AED 충전 시작          │
│ 14:31:06  리듬 VF                │
│ 14:30:40  I-gel 성공             │
├─────────────────────────────────┤
│ Cycle 3 · 02:04                  │
│ 14:28:58  리듬 PEA · 제세동 미적응│
│ 14:28:54  CPR 시작               │
├─────────────────────────────────┤
│ [리듬] [Shock/CPR] [Epi] [＋]    │
└─────────────────────────────────┘
```

### 상단 요약 헤더

스크롤해도 다음 정보는 고정한다.

- 현재 시각과 기록 상태
- 총 가슴압박 시간
- 현재 CPR cycle 번호, 잔여시간, 압박 진행/멈춤 상태
- AED 상태: 분석, 충전 중과 경과시간, 수동 모드
- 총 제세동 횟수
- Epinephrine 총 투여 횟수와 마지막 투여 후 경과시간
- 최근 리듬

총 가슴압박 시간은 `압박 시작~멈춤` 구간의 합으로 계산한다. 리듬 확인, ROSC 및 사용자가 기록한 압박 중단 구간은 포함하지 않는다.

### 초기 진행 카드

기록 시작 직후 타임라인 위에 다음 네 항목을 크게 표시한다. 완료된 항목은 시각과 함께 축소되어 한 줄 요약으로 남는다.

1. 환자 접촉
2. 심폐소생술 시작
3. AED 부착 지시 / AED 부착 완료
4. Initial rhythm 분석 / 리듬 선택

각 항목은 현재 시각으로 즉시 기록하며 길게 누르면 과거 시각을 입력한다. `AED 부착 지시`와 `부착 완료`는 별도 시각으로 기록할 수 있다.

AED 카드에는 `수동 모드 전환` 버튼을 추가한다. 버튼을 누르면 `AED 수동 모드 전환시각`을 타임라인에 남기고, 이후 AED 상태에 `MANUAL` 배지를 유지한다.

### 2분 CPR cycle 카드

Initial rhythm 이후부터 각 cycle을 하나의 카드로 표시한다.

- cycle 시작시각과 2분 타이머
- 해당 cycle의 리듬 분석시각과 리듬
- AED 충전 시작과 충전 경과시간
- 제세동 시행 또는 `제세동 미적응` 기록
- 제세동 누적 회수
- cycle 중 발생한 약물·기도·정맥로 등 병행 사건
- 실제 cycle 종료시각과 초과시간

리듬 분석, AED 충전 시작, 제세동 시행, CPR 재개는 별도 사건으로 둔다. 실제 현장에서는 각 시각이 다르고 압박 또는 다른 처치와 병행될 수 있기 때문이다. AED 충전 타이머와 가슴압박 타이머도 서로 독립적으로 움직인다. 앱이 리듬을 판단하거나 어느 버튼을 선택하라고 추천하지는 않는다.

Cycle 종료 10초 전과 5초 전에 서로 다른 햅틱을 제공한다. 2분이 지나도 사건을 자동 생성하지 않고 초과시간만 표시한다.

2분 cycle 타이머에는 일반적인 일시정지 버튼을 두지 않는다. 리듬 확인이 시작되면 현재 cycle을 종료하고 별도의 `압박 중단 타이머`를 시작한다. 압박이 재개되면 중단 타이머를 끝내고 새로운 2분 cycle을 시작한다. 이렇게 해야 2분 주기와 실제 가슴압박 시간을 서로 정확히 계산할 수 있다.

### 병행 처치 사건

병행 처치는 실제 발생시각 위치에 타임라인 행으로 삽입한다. 종류별 탭을 만들지 않고 색상·아이콘·짧은 라벨로 구분한다.

- 기도/호흡: 구강 내 이물질 확인 지시, 산소 투여 지시, 산소 유량·잔량, OPA, NPA, I-gel, Intubation, ETCO₂
- 동의/평가: SALS 동의, 녹음 시작·종료, 평소 CPC 점수
- 순환/검사: IV 확보, 수액 투여, BST 측정값, 기계식 가슴압박
- 약물: Epinephrine, Amiodarone, NS flush, 5% DW
- 운영: 의료지도 요청, 병원 선정, 병원 이송 준비 지시, 이송병원 통보
- 상태: ROSC, 재심정지

## 6. 빠른 기록 방식

### 고정 하단 버튼

진행 중에는 다음 네 버튼을 항상 같은 위치에 둔다.

1. `리듬 분석`
2. `Shock / CPR`
3. `Epinephrine`
4. `더보기`

`더보기`는 전체 화면 전환이 아니라 엄지손가락으로 닿는 바텀시트다. 최근 사용 항목을 위에 배치하며, 항목 선택 후 즉시 닫힌다.

### 공통 동작

- 단일 사건은 한 번 눌러 현재 시각으로 기록한다.
- 선택이 필요한 사건은 최대 두 번의 조작으로 끝낸다.
- 기록 즉시 햅틱과 `기록됨 · 실행 취소`를 5초간 표시한다.
- 같은 사건을 2초 안에 다시 누르면 중복 가능성을 표시한다.
- 길게 누르면 과거 시각으로 기록한다.
- 사건을 누르면 시·분·초, ±10초, ±1분, 메모, 삭제를 편집한다.

### 필수 기록 상태와 버튼 색

버튼을 한 번 눌러 기록하면 즉시 색과 내용이 바뀐다. 색만 사용하지 않고 체크 아이콘, 기록시각, 회차를 함께 표시한다.

- 회색 테두리: 아직 기록하지 않음
- 주황색: 진행 중 또는 일부만 기록됨. 예: AED 지시만 기록, 부착 미기록
- 녹색 + 체크: 필수 기록 완료
- 파란색 + 회차: 반복 가능한 사건이 한 번 이상 기록됨
- 빨간 테두리 + `미기록`: 다음 단계로 넘어갔지만 필수 기록이 빠짐

필수 기록은 두 종류로 관리한다.

- 최초 1회 필수: 환자 접촉, CPR 시작, AED 부착, Initial rhythm
- cycle별 필수: 리듬 분석, `제세동 또는 미적응`, CPR 재개

지시와 성공/완료가 분리된 버튼은 지시를 누르면 주황색, 성공/완료까지 누르면 녹색으로 바뀐다. Epinephrine, 제세동처럼 반복되는 버튼은 파란색을 유지하면서 `2회 · 14:31:12`처럼 회차와 최근 시각을 갱신한다.

필수 기록 누락이 있어도 긴급한 다른 기록을 막지는 않는다. 대신 상단에 `필수기록 6/7 · 미기록 1`을 계속 표시하고, 누르면 누락된 버튼으로 이동한다. 세션 종료 시에는 각 누락 항목에 대해 `시각 입력` 또는 `해당 없음`을 선택해야 최종 종료된다.

### 리듬 기록

`리듬 분석`을 누르면 VF, Pulseless VT, PEA, Asystole, 기타/판독 불가를 큰 버튼으로 표시한다.

- 버튼을 누른 시각에 현재 CPR 구간을 멈추고 `리듬 확인 중 00:00` 타이머를 전체 폭으로 표시한다.
- 첫 분석은 Initial rhythm으로 표시한다.
- 이후에는 각 2분 cycle의 리듬으로 표시한다.
- 리듬 분석시각과 선택한 리듬을 한 사건으로 저장한다.
- 재심정지 후 첫 리듬은 새 episode의 Initial rhythm으로 표시한다.
- 8초부터 타이머를 노란색, 10초부터 빨간색으로 바꾸고 10초에 짧은 햅틱을 제공한다.
- 리듬 선택만으로 압박 중단을 끝내지 않는다. 실제 제세동 또는 미적응 기록 후 `CPR 재개`가 기록될 때 끝낸다.

### 제세동과 가슴압박

`Shock / CPR`을 누르면 독립된 기록 버튼을 표시한다.

- `AED 충전 시작`
- `제세동 시행`
- `제세동 미적응`
- `가슴압박 재개`

`AED 충전 시작`은 별도 충전 경과 타이머를 시작한다. `제세동 시행`은 충전 타이머를 종료하고 자동으로 총 제세동 회수를 올린다. 충전 중 가슴압박이 재개되어도 두 타이머는 독립적으로 유지한다. 제세동 에너지는 추천하지 않으며 필요한 경우에만 메모한다.

`제세동 시행`과 `가슴압박 재개`를 하나로 합치지 않는다. 실제 압박이 재개된 시각에 사용자가 별도로 누르면 새 2분 cycle을 시작한다. `제세동 미적응`도 판정 기록일 뿐이며 가슴압박 재개시각은 별도로 기록한다.

기계식 가슴압박은 별도 사건으로 적용 시작시각을 남기며, 총 CPR 시간에는 계속 포함한다.

### 가슴압박 잠시 멈춤

리듬 확인 외의 이유로 실제 압박이 중단된 경우 현재 cycle 카드의 `압박 멈춤`을 누를 수 있다.

- 누르는 즉시 압박 구간을 종료하고 중단 타이머를 시작한다.
- 하단 기록 버튼은 큰 `가슴압박 재개` 버튼으로 바뀐다.
- 재개를 한 번 누르면 기본적으로 남은 cycle을 즉시 이어간다. 새 cycle로 바꿔야 할 때만 기록 후 상세에서 변경한다.
- 리듬 확인으로 중단한 경우에는 항상 새 cycle을 시작한다.
- 중단한 시간은 총 가슴압박 시간에서 제외한다.
- 실수로 누른 경우 5초 실행 취소로 원래 압박 구간을 복원한다.

중단 사유는 리듬 확인, 제세동, 기도 처치, 환자 이동, 장비 교체, 기타로 기록할 수 있다. 사유 선택은 필수가 아니며 압박 재개를 지연시키지 않는다.

### 기도와 산소

기도 항목은 `지시`와 `성공`을 분리해 기록할 수 있다.

- 산소 투여 지시 / 시작
- OPA 지시 / 적용
- NPA 지시 / 적용
- I-gel 지시 / 성공
- Intubation 지시 / 성공

- 구강 내 이물질 확인은 지시시각을 한 번 눌러 기록한다.
- 산소 유량은 시각과 L/min 값을 함께 저장한다.
- 산소 잔량은 시각과 사용자가 입력한 %, L 또는 압력 값을 함께 저장한다.
- I-gel 또는 Intubation 성공 후에는 `ETCO₂ 측정` 버튼을 가까이 표시하고 측정시각과 mmHg 값을 저장한다.

첫 버튼은 지시시각을 기록한다. 같은 항목을 다시 열면 성공/적용 시각을 한 번 눌러 기록한다.

### SALS 동의와 녹음

- `SALS 동의`를 누르면 보호자 동의시각을 기록한다.
- 녹음은 기본 OFF다.
- 사용자가 직접 ON/OFF하며 타임라인에 녹음 시작·종료시각을 표시한다.
- 녹음 중에는 화면 상단에 항상 보이는 표시를 둔다.
- 녹음 파일은 해당 SALS 세션에 연결한다.
- 실제 구현 전 Android/iOS 권한, 개인정보 보호 및 녹음 관련 법적 고지를 별도로 검토한다.

### CPC와 BST

- `평소 CPC`는 1~5 선택과 확인시각을 함께 저장한다.
- `BST`는 측정시각과 숫자 입력창을 한 화면에서 저장한다.
- 입력 완료 후 키보드를 자동으로 닫고 타임라인으로 복귀한다.

### 정맥로와 수액

- IV 확보시각을 한 번 눌러 기록한다.
- 수액 투여는 별도 시각으로 기록한다.
- 필요하면 IO 확보도 동일한 방식으로 기록한다.

### 약물

- Epinephrine은 한 번 눌러 투여시각과 총 투여 회수를 기록한다.
- 마지막 Epinephrine 이후 `00:00`부터 경과시간을 표시하고, 03:00과 04:00 경계를 색과 햅틱으로 알린다. `투여 지시` 문구는 사용하지 않는다.
- Amiodarone은 `1차 / 2차`를 선택하고 투여 용량을 숫자로 입력한다.
- NS flush 및 5% DW 지시는 연결된 약물 사건의 하위 기록으로 남긴다. 필요할 때만 타임라인에 별도 행으로 펼친다.
- 각 약물은 총 투여 횟수를 자동 집계한다.

### ROSC, 병원 선정, 재심정지

- ROSC는 시각을 기록하고 현재 CPR cycle과 episode를 종료한다.
- 병원 선정은 선정시각과 선택 메모를 기록한다.
- 병원 이송 준비 지시와 이송병원 통보는 각각 독립된 시각 사건으로 기록한다.
- 재심정지는 새 episode를 만들고 새 CPR 시작시각을 기록할 수 있게 한다.
- ROSC 이후 재심정지까지의 시간은 CPR 총 시간에 포함하지 않는다.

## 7. 세션과 저장

- 사용자가 `SALS 기록 시작`을 눌러 새 세션을 만든다.
- 세션은 현재 환자에 연결한다.
- 진행 중 세션이 있으면 `이어하기` 또는 `종료 후 새 기록`을 선택한다.
- 앱을 종료했다가 다시 열어도 timestamp를 기준으로 경과시간을 복원한다.
- ROSC가 되어도 사용자가 종료하기 전까지 같은 세션을 유지한다.
- 종료된 세션은 기록 목록에서 다시 볼 수 있다.
- 사용자는 종료된 기록을 확인 절차 후 직접 삭제할 수 있다.
- 삭제는 해당 세션만 대상으로 하며 다른 환자 기록에 영향을 주지 않는다.

## 8. 기록 데이터

### 세션

- 세션 ID
- 환자 ID
- 시작·종료 시각
- 진행 상태

### Episode

- 최초 심정지 또는 재심정지 구분
- 시작·종료 시각
- 최초 리듬

### CPR cycle

- cycle 번호
- 시작·종료 시각
- 연결된 episode
- 압박 구간과 압박 중단 구간
- 중단 사유와 중단 지속시간

### 사건

- 사건 ID와 종류
- 발생시각
- 입력시각
- 자동 회차
- 단계: 지시, 시작, 성공, 적용, 투여, 측정, 상태 변화
- 값: 리듬, CPC, BST, Amiodarone 용량 등 사건별 입력값
- 상위 사건 ID: 약물과 NS flush/5% DW처럼 서로 연결되는 기록
- 완료 상태: 미기록, 진행 중, 완료, 해당 없음
- 필수 여부와 필수 범위: 최초 1회 또는 cycle별
- 선택 메모
- 수정 전 값과 수정시각

활력징후를 기록할 때는 메모 화면에 입력된 당시 값을 복사하여 이후 값이 변경되어도 SALS 기록이 바뀌지 않게 한다.

## 9. 기존 기록 마이그레이션

- 기존 `ems-log.sals-events.v1` 배열은 삭제하지 않는다.
- 새 버전 최초 실행 시 `이전 SALS 기록`이라는 하나의 종료 세션으로 변환한다.
- 기존 timestamp, kind, label, detail을 그대로 보존한다.
- 환자 ID를 알 수 없으면 `미지정 환자`로 표시한다.
- 마이그레이션 완료 표시를 저장하여 중복 변환을 방지한다.
- 변환에 실패하면 원본 데이터를 유지하고 다시 시도할 수 있게 한다.

## 10. PDF·이미지 내보내기

- 종료된 세션을 PDF 또는 긴 이미지로 기기에 저장한다.
- 출력 내용은 세션 시작·종료, 전체 경과, episode 구분, 시간순 사건 목록이다.
- 병원 인계 서식이나 공식 문서 표현을 사용하지 않는다.
- 저장 전에 환자 식별정보 포함 여부를 선택한다.
- 파일 상단에 `개인 기록용`을 표시한다.

## 11. 디자인 기준

- 핵심 버튼 높이 56dp 이상
- 모든 터치 영역 최소 48×48dp
- 장갑을 낀 상태에서도 구분되는 간격
- 숫자는 고정폭, 사건명은 한 줄 우선
- 색상과 함께 아이콘·텍스트를 병용
- 라이트·다크 모드 지원
- Android/iOS 하단 시스템 영역과 겹치지 않음
- 타이머 갱신 중에도 버튼 입력과 스크롤이 끊기지 않음

색상은 CPR 청록, 리듬 보라, 제세동 주황, 약물 파랑, ROSC 녹색으로 구분하되 색만으로 의미를 전달하지 않는다.

## 12. 안전 원칙

- 화면 정보 메뉴에 `시행된 처치와 시각을 기록하는 개인용 도구이며 의료지시를 대체하지 않습니다.`를 표시한다.
- 약물 용량·경로, 제세동 에너지, 다음 처치를 추천하지 않는다.
- 리듬 결과를 기준으로 다음 행동 버튼을 자동 추천하지 않는다.
- 타이머는 시간을 보여줄 뿐 사건이나 처치를 자동 기록하지 않는다.
- 저장 실패와 타이머 오류는 즉시 표시한다.

## 13. MVP 구현 범위

1. 환자별 SALS 세션
2. 기존 기록 마이그레이션
3. 단일 열 타임라인
4. 상단 고정 상태 헤더
5. 환자 접촉·CPR·AED·Initial rhythm 초기 진행 카드와 필수 완료 상태
6. 하단 고정 기록 버튼과 더보기 바텀시트
7. 리듬 분석·AED 충전·제세동/미적응·CPR 재개·2분 cycle·압박 중단 타이머
8. 구강 이물질 확인, 산소 유량·잔량, 기도 지시·성공, ETCO₂ 수치
9. SALS 동의시각, CPC, IV/IO, 수액, BST
10. Epinephrine 경과 타이머와 Amiodarone 용량
11. 약물별 총 횟수, 총 CPR 시간, 총 제세동 회수
12. AED 수동 모드 전환, 기계식 가슴압박, 의료지도 요청, 병원 선정·이송 준비·통보
13. ROSC와 재심정지 episode
14. 5초 실행 취소와 초 단위 시각 수정
15. 앱 재실행 후 세션 복구
16. 필수 기록 누락 표시와 종료 전 확인
17. 종료 기록 확인과 직접 삭제

후속 단계에서 실제 녹음 파일 저장과 PDF·긴 이미지 내보내기를 구현한다. 녹음은 SALS 동의시각이 기록된 경우에만 시작하고, 마이크 권한·녹음 상태·시작/종료시각·세션별 파일을 관리한다. 종료된 기록은 개인 기록용 PDF 또는 긴 이미지로 시스템 공유창을 통해 저장한다.

## 14. 완료 기준

- 자주 쓰는 사건을 두 번 이하의 탭으로 기록할 수 있다.
- 전체 경과와 CPR 잔여시간이 스크롤 없이 보인다.
- 방금 기록한 사건이 즉시 타임라인 최상단에 나타난다.
- 초기 진행 네 항목의 완료 여부와 시각을 한 카드에서 확인할 수 있다.
- 매 2분 cycle에서 리듬, AED 충전, 제세동 또는 미적응, CPR 재개시각을 한 카드로 확인할 수 있다.
- AED 수동 모드 전환시각이 기록되고 이후 상태에 MANUAL 표시가 유지된다.
- AED 충전 타이머와 가슴압박 타이머가 독립적으로 동작한다.
- 기록된 버튼은 색, 체크, 시각 또는 회차로 완료 여부를 보여준다.
- 필수 기록이 빠지면 상단에 미기록 수가 유지되고 종료 전에 시각 입력 또는 해당 없음으로 처리한다.
- 리듬 분석을 누르면 별도 압박 중단 타이머가 즉시 시작되고 CPR 재개 시 종료된다.
- 일반 압박 중단과 재개를 한 번 눌러 기록하고 중단시간을 총 CPR 시간에서 제외한다.
- 리듬 확인 중단이 10초를 넘으면 화면과 햅틱으로 알아차릴 수 있다.
- 서로 다른 환자의 사건이 섞이지 않는다.
- 오입력을 5초 안에 바로 취소할 수 있다.
- 발생시각을 초 단위로 수정할 수 있다.
- ROSC와 재심정지가 서로 다른 episode로 보인다.
- 총 CPR 시간, 제세동 회수, 약물별 회수가 자동 집계된다.
- Epinephrine은 마지막 투여 후 경과시간과 3~4분 구간을 표시한다.
- 약물·제세동 화면은 처치를 권고하는 문구를 사용하지 않는다.
- 앱 재실행 후 진행 중 세션과 타이머가 복구된다.
- 기존 SALS 데이터가 한 번만 안전하게 변환된다.
- 하단 버튼이 Android 시스템 내비게이션과 겹치지 않는다.

## 15. 참고 근거

국내 현장 용어와 기록 항목은 [소방청 119구급대원 현장응급처치 표준지침](https://www.nfa.go.kr/nfa/publicrelations/legalinformation/archives/?boardId=bbs_0000000000000018&cntId=50&mode=view)을 참고한다. CPR cycle과 성인 심정지 흐름은 [AHA 2025 Adult Advanced Life Support](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/adult-advanced-life-support) 및 [Adult Cardiac Arrest Algorithm](https://cpr.heart.org/-/media/CPR-Files/CPR-Guidelines-Files/2025-Accessible/Algorithm-ACLS-CA-LngDscrp-250725-Ed.pdf)을 참고한다. 리듬·맥박 확인은 10초를 넘기지 않고 압박 중단을 최소화해야 한다는 기준은 [AHA 2025 Adult Basic Life Support](https://cpr.heart.org/en/resuscitation-science/cpr-and-ecc-guidelines/adult-basic-life-support)를 참고한다. 앱은 이 기준을 처치 지시가 아닌 중단시간 기록과 시각·햅틱 피드백으로만 구현한다.
