# 코드 리뷰 수정 — 2026-10-08

- 리듬 리셋은 표시와 횟수를 제거하되 압박 중지 경계를 내부에 보존한다. 숨긴 경계는 저장·복구 후에도 계산에 사용한다.
- SALS 복구 실패 시 변경과 자동 저장을 차단해 기존 데이터를 보호한다. 앱 재실행으로 복구를 다시 시도한다.
- 신분증 촬영 원본·OCR 임시 파일과 등록 전 실패한 이미지 사본은 정리한다. 정상 등록된 이미지만 유지한다.
- 환자 초기화는 예약된 저장을 취소하고 이전 저장 뒤에 빈 데이터를 기록한다. 저장 완료 후 화면과 첨부 자료를 비운다. 저장 실패 시 실패 안내를 표시한다.
- 신분증 인식 중에는 초기화를 막아 처리 완료 후 자료가 다시 등록되는 충돌을 방지한다.
