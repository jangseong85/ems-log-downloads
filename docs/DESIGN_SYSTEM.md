# EMS Log 디자인 기준

## 적용 범위

환자 기록, 활력징후, 과거력, 필기 도구, 카메라 안내, 설정 및 향후 SALS 화면에 공통 적용한다. 기능과 기록 저장 정책은 변경하지 않는다.

## 타이포그래피

Pretendard를 유지한다. 화면 제목 24/600, 섹션 제목 18/500, 입력·본문 16/400, 라벨·버튼 14/500, 보조 설명·단위 12/400을 기본으로 한다. 활력징후 숫자는 24/500을 사용한다. 작은 글씨의 과도한 Bold 강조를 없앤다.

`src/design.ts`의 역할별 규칙을 거쳐 실제 폰트 파일에 매핑한다. 새 화면은 별도 임의 규격 대신 공통 역할에 등록한다. 향후 SALS 타이머는 별도 숫자 역할(36/24, 고정폭)을 추가한다.

## 형태와 간격

페이지 여백·영역 간격 16, 입력 및 주요 컨트롤 최소 높이 48, 컨트롤 모서리 12, 카드 모서리 16. 카드 그림자는 사용하지 않는다. 원형 카메라 버튼과 미디어 프레임은 목적에 맞는 기존 형태를 유지한다.

## 색상

기존 라이트 화이트·틸(#087F6D), 다크 딥 그린·민트(#67D2BC) 정체성을 유지한다. 선택·행동은 틸/민트, 삭제·기존 경고는 레드이며 의미를 텍스트와 함께 표시한다. SALS만 다른 기본색으로 만들지 않는다.

## 접근성과 검증

Text/TextInput의 기본 글자 확대를 끄지 않는다. 컨트롤은 고정 높이 대신 최소 높이로 확장 가능하게 한다. 본 변경은 iOS Dynamic Type의 네이티브 의미별 스타일 전체 구현이 아니며, 실제 기기의 큰 글자 설정에서 날짜·과거력·필기 도구·하단 메뉴의 잘림을 추가 확인해야 한다. 작은 화면의 고정 폭 날짜 입력과 이미지 관련 영역은 별도 레이아웃 검증이 필요하다.

2026-10-08: 전체 공통 타이포와 컨트롤 규격을 소스에 적용. SALS 신규 기능 및 APK 빌드는 포함하지 않는다.
