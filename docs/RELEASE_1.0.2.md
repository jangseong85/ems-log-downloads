# EMS Log 1.0.2

배포일: 2026-10-08 · Android versionCode: 3 · 패키지: com.emslog.mobile

- 압박 구간과 2분 사이클을 수동 시작하고, 리듬 분석 중 압박 시간을 제외한다.
- 교대 준비 표시, Epinephrine 참고 링, 투약 시각 목록과 사건별 타임라인 색상을 적용했다.
- 반복 ROSC·재심정지 경과를 구분하고 날짜·시작 시각을 정리했다.
- 리듬 리셋 후에도 압박 중지 경계를 보존하고 SALS 복구 실패 시 기존 기록의 덮어쓰기를 차단했다.
- OCR 오류 후 등록되지 않은 신분증 이미지를 정리하고 환자 초기화 저장 순서를 보장했다.

ARM64 APK. 기존 홈페이지 배포 인증서를 유지하며 versionCode를 2에서 3으로 올린다.
타입 검사·린트·SALS 단위 테스트 14개 통과. 카메라·저장 실패와 강제 종료 등 실기기 검증은 별도로 필요하다.
타이머는 사용자의 수동 기록 기준이며 치료 권고나 자동 투약 지시를 제공하지 않는다.
